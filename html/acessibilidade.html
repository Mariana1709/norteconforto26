Acessibilidade

A Norteconforto procura disponibilizar um website acessível, intuitivo e fácil de utilizar por todos os visitantes.

Compromisso com a acessibilidade

Este website foi desenvolvido com o objetivo de proporcionar uma experiência de navegação simples, confortável e inclusiva para todos os utilizadores.

Para melhorar a acessibilidade, disponibilizamos um painel de ferramentas acessível através do botão flutuante presente em todas as páginas do website.

Caso encontre alguma dificuldade de navegação ou algum problema de acessibilidade neste website, contacte-nos através da página de contactos para que possamos melhorar continuamente a experiência dos nossos utilizadores.

Funcionalidades Disponíveis

Leitor de Texto

Permite ouvir o conteúdo das páginas através de síntese de voz.

Tamanho do Texto

Permite aumentar ou reduzir o tamanho dos conteúdos.

Modo Escuro

Alterna entre tema claro e escuro para maior conforto visual.

Pesquisa

Localiza rapidamente conteúdos e páginas do website.

Repor Definições

Repõe todas as opções de acessibilidade para os valores originais.
